# StonkFun Tracking

Unofficial companion to [StonkFun](https://www.stonkfun.xyz). Filter tokens by market cap, 24h volume, and age at the same time.

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).
